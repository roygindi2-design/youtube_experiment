# דוח העלאה — "¡Rojito cambia de color!" (Rojito, ראשון בשיטת הבמאי)
**קישור:** https://youtube.com/shorts/0WpO8lYXsEU · **סדרה:** Rojito · **הועלה:** 21.10, ~01:40 ישראל · **אורך:** 26.5 ש'

## 1. מחקר לפני התסריט
1. סריקת פורמטים לסדרה 2: רכבים ×38.8 (57 Shorts) — הכי חזק.
2. outliers ברכבים+צבעים: "El camión de bomberos cambia de color" 6.7M ×412; "Pelotas de colores y coches" 12.1M ×743; "Bolas de colores caen por el tobogán" 7.5M ×460.
3. מחקר עלילה (40 outliers, research/09): דפוס "ניחוש אינטראקטיבי" — TikiTykes "guess the next color" 20.1M ×1,171.
4. מקרה NuNu (Roy, research/10): שורה בשיר = מה שרואים, על הפעמה.
5. משוב Roy על Rojito 1: "לא קורה כלום" → שיטת במאי + סטוריבורד.

## 2. 3 סיבות
1. אותו נושא בדיוק הוכח (6.7M). 2. צבעים+רכבים מנצח גם כשצבעים לבד צפוף. 3. ניחוש ("¿De qué color?") = הילד צועק, צפייה חוזרת.

## 3. עלילה
- **דפוס:** ניחוש אינטראקטיבי. **פתיחה חדשה:** splash כחול בשנייה 0 (לא זום).
- **רצף:** אדום ← splash כחול ← רוחיטו כחול ("¡Azul!") ← splash צהוב ← צהוב עם כתמים ירוקים ← ירוק ומודאג ("¿Dónde está Rojito?") ← splash אדום — חוזר להיות עצמו ← קשת ← "¡No!" בדיוק כשטיפה סגולה נוחתת עליו (פואנטה + לופ).
- **מוסר:** "Rojito sigue siendo Rojito".

## 4. הפקה ו-QC
- 16 keyframes (2 לשוט) → נבחרו 8; 22 קליפים. QC אוטומטי FAIL בשוטי splash — נבדק ויזואלית; C6 נחתך ל-1.6 ש' (מורף "רגליים").
- עריכה לפי זמני מילים (edit_cuts.py), בלי הקפאות; חזרה = ניגון לאחור.
- מטא-דאטה בסגנון NuNu: #shorts, קישורים, האשטגים, תגיות ספרדית+אנגלית.
- עלות היום הכוללת ~$8.1.
